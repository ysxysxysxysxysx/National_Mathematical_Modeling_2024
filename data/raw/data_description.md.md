# 数据格式说明

## 附件一：热解数据统计

该数据包含每条实验记录的详细信息，主要字段如下：

| 字段名              | 说明                                 | 单位 |
| ------------------- | ------------------------------------ | ---- |
| 时间                | 实验日期                             | -    |
| 试样                | 原料名称（如 CS/HN 表示棉杆/淮南煤） | -    |
| 配比                | 生物质与煤的混合比例（如 5/100）     | -    |
| 样品g               | 样品质量                             | g    |
| 焦油(Char)g         | 焦油质量                             | g    |
| 水(Water)mL         | 水体积                               | mL   |
| 正己烷不溶物（INS)g | 正己烷不溶物质量                     | g    |
| 焦油产率            | 焦油质量 / 样品质量                  | wt%  |
| 水产率              | 水质量 / 样品质量                    | wt%  |
| 焦渣产率            | 焦渣质量 / 样品质量                  | wt%  |
| 正己烷可溶物产率    | 正己烷可溶物质量 / 样品质量          | wt%  |

## 附件二：热解产物产率计算结果

包含10种共热解组合的实验数据与理论计算值，每种组合包含：

- Tar（焦油产率）
- HEX（正己烷可溶物产率）
- Water（水产率）
- Char（焦渣产率）

每种产物都有实验值（Experimental）和理论计算值（Calculated）。
