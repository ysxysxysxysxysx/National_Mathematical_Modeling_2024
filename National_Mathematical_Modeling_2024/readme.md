# 生物质与煤共热解产物产率预测与优化

> 2024年第九届"数维杯"大学生数学建模挑战赛 B题

## 一、项目简介

生物质与煤共热解是一种将可再生能源与传统化石燃料结合的新型能源转化技术。  
本项目通过**机器学习模型**预测热解产物产率，并利用**遗传算法**优化生物质与煤的混合比例，以最大化焦油产量。

## 三、核心方法与结果

| 问题                           | 方法                                        | 核心结果                                 |
| ------------------------------ | ------------------------------------------- | ---------------------------------------- |
| 问题1：INS对热解产率的影响     | Spearman/Pearson/Kendall相关系数 + 线性回归 | INS与焦油产率相关系数为 0.1505，影响较弱 |
| 问题2：INS与混合比例的交互效应 | 多元线性回归 + 怀特异方差检验 + VIF检验     | 混合比例对焦油产率有显著正向影响         |
| 问题3：优化混合比例            | 改进遗传算法（双目标转单目标）              | 焦油产率最大可达 **15.18 wt%**           |
| 问题4：实验值与理论值的差异    | 配对样本t检验                               | 3种组合存在显著差异                      |
| 问题5：预测热解产物产率        | **LR-XGBoost融合模型**（加权平均融合）      | 测试集 R² = **0.96**，RMSE = **0.007**   |

## 六、 技术亮点

1. **LR-XGBoost融合模型**：将线性回归与XGBoost结合，兼顾可解释性与预测精度
2. **改进遗传算法**：将双目标优化转化为单目标优化，引入自适应权重
3. **完整的统计检验流程**：相关性分析 → 回归建模 → t检验验证 → 预测优化
