# 生物质与煤共热解产物产率预测与优化

> 基于统计分析、机器学习与改进免疫遗传算法的共热解产率预测及配比优化项目  
>
> 2024年第九届"数维杯"大学生数学建模挑战赛 B题

## 一、项目简介

- 生物质与煤共热解是一种将可再生能源与传统化石燃料结合的新型能源转化技术。  

- 本项目通过**机器学习模型**预测热解产物产率，并利用**遗传算法**优化生物质与煤的混合比例，以最大化焦油产量。

- 不同原料组合和混合比例可能产生完全不同的热解结果，因此如何从实验数据中分析关键影响因素、预测不同条件下的产物产率，并进一步寻找最优混合方案，是本项目需要解决的核心问题。
- 本项目基于实验数据，综合使用：
  - 相关性分析
  - 多元线性回归
  - 配对样本 t 检验
  - 改进免疫遗传算法
  - Random Forest
  - SVM
  - XGBoost
  - LR-XGBoost 融合模型

- 构建了一套完整的：


​       **数据预处理 → 影响因素分析 → 协同效应验证 → 机器学习预测 → 智能配比优化**

​       技术流程。

## 六、项目难点

### 6.1小样本且数据分布复杂

实验数据量有限，部分变量存在：

- 缺失值
- 异常值
- 偏态分布
- 非正态分布

传统依赖正态分布假设的统计方法可能导致分析结果不稳定。

因此，本项目需要针对小样本实验数据选择更加鲁棒的统计分析方法。

### 6.2 多个因素同时影响热解产率

热解产率并不是由单一因素决定。

例如：

- INS 可能影响焦油产率；
- 混合比例也可能影响焦油产率；
- 原料种类同样可能产生影响。

仅使用简单相关性分析无法判断各变量在控制其他因素后的独立影响，因此需要进一步建立多变量统计模型。

### 6.3 混合比例与产率之间存在复杂关系

混合比例与焦油等产物产率之间难以获得明确的解析函数。

该优化问题具有：

- 非线性
- 多约束
- 多目标
- 搜索空间复杂

等特点。

传统梯度优化方法依赖可导目标函数，并且容易受到初始值影响，因此难以直接应用。

### 6.4 遗传算法容易出现早熟收敛

传统遗传算法虽然具有较强的全局搜索能力，但仍可能出现：

- 初始种群分布不均
- 种群多样性快速下降
- 优秀个体在交叉和变异过程中丢失
- 提前收敛到局部最优
- 约束条件难以直接处理

因此，本项目在传统遗传算法基础上引入免疫机制、混沌初始化、惩罚函数和精英保留等策略。

### 6.5 单一机器学习模型泛化能力有限

实验数据同时包含：

- 类别变量
- 连续变量
- 线性关系
- 非线性关系

单一模型很难同时学习这些特征。

例如线性回归具有较好的稳定性和可解释性，但对复杂非线性关系建模能力有限；XGBoost 可以学习复杂非线性关系，但在小样本条件下同样存在泛化风险。

因此，本项目进一步采用模型融合提高预测能力。

## 八、 数据预处理

### 8.1 缺失值处理

首先对数据完整性进行检查。

针对部分实验指标存在的缺失情况，根据实验背景进行处理，避免缺失值影响后续统计分析和机器学习训练。

### 8.2 正态性检验

使用 Shapiro-Wilk 检验判断变量是否满足正态分布假设。

原假设：

- H0：样本来自正态分布。

当：

```text
p < 0.05
```

时拒绝原假设，认为数据不满足正态分布。

由于部分实验数据表现出明显的非正态特征，因此后续相关性分析同时引入非参数统计方法。

### 8.3 异常值检测

针对非正态数据，使用 IQR 方法进行异常值分析。

```text
IQR = Q3 - Q1
```

异常值范围：

```text
x < Q1 - 1.5 * IQR
```

或：

```text
x > Q3 + 1.5 * IQR
```

相比基于均值和标准差的 3σ 方法，IQR 对偏态数据和极端值更加鲁棒。

### 8.4 类别特征编码

生物质种类和煤种属于类别变量，机器学习模型无法直接处理字符串类型，因此使用 One-Hot Encoding 将类别特征转换为数值特征。

### 8.5 特征标准化

不同实验指标具有不同量纲和数值范围。

针对需要进行尺度统一的模型，对连续特征进行标准化处理，减少不同量纲对模型训练过程的影响。

## 九、核心算法一：相关性分析

### 9.1 问题

INS 是否与焦油、水和焦渣产率存在明显相关关系？

### 9.2 方法

为了降低异常值和非正态分布对结论的影响，同时采用：

- Pearson 相关系数
- Spearman 相关系数
- Kendall 相关系数

进行分析。

#### Pearson

主要衡量两个连续变量之间的线性相关关系。

#### Spearman

首先对数据进行排序，再计算秩之间的相关性，对异常值更加鲁棒。

#### Kendall

通过比较样本对之间排序的一致性判断相关程度，适合小样本数据。

### 9.3 结论

分析结果表明：

INS 与焦油产率之间的相关程度较弱。

因此可以认为：

**INS 并不是决定焦油产率的主要因素。**

这一结论进一步引出了后续问题：

> 如果 INS 不是主要影响因素，那么混合比例是否才是影响焦油产率的重要因素？

## 十、核心算法二：多元线性回归

### 10.1 问题

相关性分析只能说明两个变量之间是否存在关系，但不能很好地回答：

> 当 INS 和混合比例同时变化时，哪个变量对产率的影响更加明显？

因此进一步建立多元线性回归模型。

### 10.2 模型

建立：

```text
Y = β0 + β1 * INS + β2 * Ratio + ε
```

其中：

- Y：焦油、水或焦渣产率
- INS：正己烷不溶物
- Ratio：混合比例
- β0：截距
- β1、β2：不同变量对应的回归系数
- ε：随机误差

通过回归系数判断影响方向，通过 p 值判断变量影响是否显著。

通常：

```text
p < 0.05
```

认为变量具有统计显著性。

### 10.3 模型验证

#### VIF

使用方差膨胀因子 VIF 检查自变量之间是否存在严重多重共线性。

#### White Test

使用 White 检验分析回归残差是否存在异方差问题。

### 10.4 结论

对于焦油产率：

- INS：p = 0.062 > 0.05
- 混合比例：p < 0.001

说明：

**INS 对焦油产率的影响没有达到显著水平，而混合比例对焦油产率具有显著影响。**

因此，后续优化重点从 INS 转向：

**如何寻找更加合理的生物质/煤混合比例。**

## 十一、核心算法三：改进免疫遗传算法

### 11.1 问题

在确定混合比例是重要影响因素之后，需要进一步解决：

> 生物质与煤按照什么比例进行共热解，可以获得更优的产物产率？

这一问题具有以下特点：

- 目标函数关系复杂
- 难以获得显式可导函数
- 存在多个约束
- 存在多个优化指标
- 容易出现局部最优

因此采用具有全局搜索能力的遗传算法。

同时针对传统遗传算法容易出现的早熟收敛和种群多样性下降问题，引入免疫机制进行改进。

### 11.2 编码

遗传算法首先需要将实际优化方案转换为染色体。

基本思想为：

```text
实际混合比例
      |
      v
二进制染色体
```

假设采用 n 位二进制编码：

```text
000...000
...
111...111
```

可以表示：

```text
0 ~ (2^n - 1)
```

再通过线性映射将其转换到实际混合比例区间。

例如比例范围为 [0,1]：

```text
x = D / (2^n - 1)
```

其中：

- D：二进制染色体对应的十进制数
- x：实际混合比例

> 注：具体编码长度以项目实际实现为准。

### 11.3 混沌初始化

传统遗传算法通常采用完全随机方式初始化种群。

随机初始化可能导致：

- 部分区域个体过于集中
- 部分搜索空间没有被覆盖

因此引入混沌映射生成初始种群。

混沌序列具有较好的遍历性，可以提高初始种群的：

- 多样性
- 搜索空间覆盖率

从而降低算法从初始阶段就陷入局部区域的风险。

### 11.4 适应度评估

每一个染色体都对应一个候选混合方案。

将染色体解码得到实际比例后，计算该方案对应的目标函数：

```text
Fitness = F(x)
```

目标值越好，适应度越高。

遗传算法随后根据适应度判断：

**哪些方案应该被保留，哪些方案应该逐渐淘汰。**

### 11.5 惩罚函数

仅使用目标函数存在一个问题：

某些方案虽然目标值很高，但可能违反实际约束。

因此引入惩罚函数：

```text
Fitness(x) = F(x) - Σ λi * max(gi(x), 0)
```

其中：

- F(x)：原始目标值
- gi(x)：第 i 个约束的违反程度
- λi：惩罚系数

如果方案满足约束：

```text
max(gi(x), 0) = 0
```

不产生惩罚。

如果方案违反约束，则根据违反程度降低适应度。

可以概括为：

> 通过“目标函数值 - 惩罚项”评价候选方案，对违反约束的方案按违反程度扣分，惩罚系数控制扣分强度，从而引导算法在满足约束的前提下寻找最优解。

### 11.6 轮盘赌选择

采用轮盘赌方法选择下一代个体。

```text
Pi = Fitness_i / Σ Fitness_j
```

因此：

- 适应度高的个体被选择概率更高
- 适应度较低的个体仍具有一定概率被保留

这样既能实现“优胜劣汰”，又能避免种群过快失去多样性。

### 11.7 精英保留与免疫机制

为了避免已经找到的优秀方案在交叉、变异过程中被破坏，将当前最优个体直接保留到下一代。

同时引入免疫算法思想：

- 优化问题对应“抗原”
- 候选方案对应“抗体”
- 方案质量对应“亲和度”

通过亲和度评价和优秀个体记忆，提高优质解的保留能力，同时维持种群多样性。

### 11.8 交叉

从父代种群中选择个体进行交叉，将两个候选方案中的部分基因重新组合。

其核心目的为：

> 将不同优秀方案中的有效信息重新组合，产生新的候选方案。

从而扩大搜索范围。

### 11.9 变异

为了避免所有个体逐渐变得相似，对部分二进制基因随机进行翻转：

```text
0 -> 1
1 -> 0
```

变异能够产生种群中原本不存在的新方案，提高算法跳出局部最优的能力。

### 11.10 多目标加权

对于多个优化目标，采用加权方式构造综合目标函数：

```text
F = w1 * f1 + w2 * f2
```

并满足：

```text
w1 + w2 = 1
```

通过加权将双目标优化问题转换为单目标优化问题，使遗传算法可以使用统一的适应度进行搜索。

> 原项目资料给出了加权处理思想，但没有进一步给出权重自动确定方法，因此这里不将“自适应权重”作为已经实现的功能。

### 11.11 亲和度优化

在综合目标函数基础上进一步进行亲和度变换。

其主要目的是：

**扩大优秀个体与普通个体之间的评价差异。**

这样在选择阶段，真正优秀的候选方案能够更加容易地被识别和保留，从而提高算法的选择灵敏度和搜索精度。

### 11.12 改进点总结

相比传统遗传算法，本项目主要进行了以下优化：

1. **混沌初始化**：提高初始种群多样性和搜索空间覆盖率。
2. **免疫机制**：保留优秀个体并维持种群多样性，降低早熟收敛风险。
3. **惩罚函数**：处理约束条件，引导算法搜索可行解。
4. **轮盘赌 + 精英保留**：兼顾优秀方案继承和全局探索能力。
5. **交叉与变异**：产生新的候选方案，提高跳出局部最优的能力。
6. **多目标加权与亲和度优化**：统一多个优化目标，提高候选解区分度和搜索精度。

### 11.13 优化结果

通过改进免疫遗传算法进行搜索，得到的主要优化结果包括：

| 指标  |     优化结果 |
| ----- | -----------: |
| Tar   | 约 15.18 wt% |
| HEX   | 约 10.41 wt% |
| Water | 约 12.56 wt% |

## 十二、核心算法四：协同效应分析

### 12.1 问题

生物质与煤混合后得到的产物是否只是两种原料单独热解结果的简单叠加？

如果不是，则说明两种原料之间可能存在协同作用。

### 12.2 理论产率模型

假设生物质和煤之间完全不存在相互作用，则共热解理论产率可以通过线性加权得到：

```text
Y_theory = x * Y_b + (1 - x) * Y_c
```

其中：

- x：生物质比例
- Y_b：生物质单独热解产率
- Y_c：煤单独热解产率

### 12.3 协同效应

将真实实验产率与理论产率进行比较：

```text
ΔY = Y_exp - Y_theory
```

如果：

```text
ΔY > 0
```

说明实际产率高于简单线性叠加结果。

如果：

```text
ΔY < 0
```

说明实际产率低于理论结果。

但仅观察差值无法判断差异是否由随机实验误差造成，因此进一步进行统计检验。

### 12.4 配对样本 t 检验

由于实验值和理论值是在同一实验条件下形成的一一对应数据，因此使用配对样本 t 检验。

首先计算：

```text
di = Y_exp,i - Y_theory,i
```

然后检验：

```text
H0: μd = 0
```

即：

实验值与理论值不存在显著差异。

如果：

```text
p < 0.05
```

则拒绝原假设，认为实验值与理论值之间存在显著差异。

### 12.5 结果

分析发现以下组合表现出显著差异：

- RH/HN
- GA/NM
- SD/HS

说明这些原料组合的实际共热解结果明显偏离简单线性叠加结果，可能存在较明显的协同作用。

## 十三、 核心算法五：机器学习产率预测

### 13.1 问题

统计分析可以解释变量之间的关系，但实际应用中还需要解决：

> 给定一种新的原料组合和混合比例，能否直接预测对应的热解产率？

因此进一步构建机器学习回归模型。

模型输入包括：

- 生物质类型
- 煤种
- 混合比例
- INS 等实验特征

模型输出包括：

- Tar
- Water
- Char
- HEX

### 13.2 Random Forest

随机森林通过训练多棵决策树，并对多棵树的结果进行集成预测。

优势：

- 能够处理非线性关系
- 对异常值具有一定鲁棒性
- 可以分析特征重要性

但在当前小样本数据上，测试集表现存在一定局限。

### 13.3 SVM / SVR

支持向量回归通过寻找合适的回归超平面完成预测。

通过核函数可以将原始特征映射到高维空间，从而处理非线性关系。

优势：

- 适合小样本问题
- 泛化能力较强

但模型对：

- C
- gamma
- kernel

等超参数较为敏感。

### 13.4 XGBoost

XGBoost 属于 Gradient Boosting Tree 模型。

其核心思想是：

> 每一棵新树不断学习前面模型没有预测好的部分。

最终模型可以表示为：

```text
ŷ = Σ fk(x)
```

通过多棵弱学习器逐步拟合复杂的非线性关系。

XGBoost 能够较好地学习：

**原料类型 + 混合比例 + 实验条件**

与热解产率之间的复杂映射关系。

## 十四、LR-XGBoost 融合模型

### 14.1 为什么进行模型融合

单独使用线性回归：

优点：

- 稳定
- 简单
- 可解释

缺点：

- 难以拟合复杂非线性关系

单独使用 XGBoost：

优点：

- 非线性建模能力强
- 可以学习复杂特征交互

因此将两者进行融合。

### 14.2 融合方法

分别训练：

- Linear Regression
- XGBoost

得到两个预测结果：

```text
ŷ_LR
```

和：

```text
ŷ_XGB
```

最终：

```text
ŷ_fusion = w_LR * ŷ_LR + w_XGB * ŷ_XGB
```

并满足：

```text
w_LR + w_XGB = 1
```

这样可以同时利用：

- LR 对整体线性趋势的学习能力
- XGBoost 对复杂非线性关系的拟合能力

### 14.3 模型结果

最终融合模型获得较好的预测效果：

| 指标 |     结果 |
| ---- | -------: |
| R²   |  约 0.96 |
| RMSE | 约 0.007 |

## 十五、 项目核心优化点

### 15.1 统计分析优化

**问题：**

小样本、非正态、存在异常值。

**优化：**

Shapiro-Wilk + IQR + Pearson/Spearman/Kendall 多方法联合分析，提高统计结果鲁棒性。

### 15.2 多因素分析优化

**问题：**

简单相关性无法区分不同变量的独立影响。

**优化：**

使用多元线性回归，并结合 VIF 与 White Test 对模型进行统计验证。

### 15.3 全局优化算法改进

**问题：**

传统遗传算法容易出现种群多样性下降和早熟收敛。

**优化：**

引入：

- 混沌初始化
- 免疫机制
- 惩罚函数
- 精英保留
- 轮盘赌选择
- 交叉与变异
- 多目标加权
- 亲和度优化

提高全局搜索能力和优化稳定性。

### 15.4 预测模型优化

**问题：**

单一模型难以同时处理整体线性趋势和复杂非线性关系。

**优化：**

构建 LR-XGBoost 融合模型，将线性模型的稳定性与树模型的非线性建模能力结合，提高预测性能。
